# Security Policy

## Reporting a vulnerability

Please **do not open a public issue** for security vulnerabilities. Report
them privately so they can be fixed before details are exposed:

- Use GitHub's **Private vulnerability reporting** from the repository's
  Security tab, or
- Email the maintainers at a contact you know is reachable, referencing
  `opencode-vscode` and the affected version.

Include in the report:

- The extension version affected (the `version` field in `package.json`, or
  the version shown in the VS Code Extensions view).
- The VS Code version and the host you run on (e.g. Windows + Remote - WSL).
- A minimal description of the vulnerability and, if possible, a
  reproduction.
- Any suggested mitigation you are aware of.

## Response timeline

We aim to:

- Acknowledge the report within **72 hours**.
- Provide an assessment and, if confirmed, a fix in the next release.

## Supported versions

Only the **latest release** receives security fixes. Please upgrade to the
newest version from the [VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=sriruma.opencode-vscode)
or [Releases](https://github.com/SrIruma/opencode-vscode-extension/releases).
